# Componentes Futuristas do 21st.dev

## Botões Selecionados:

### 1. Rainbow Button
- **URL:** https://21st.dev/community/components/dillionverma/rainbow-button
- **Descrição:** Botão animado com efeito arco-íris
- **Instalação:** `npx shadcn@latest add https://21st.dev/r/dillionverma/rainbow-button`
- **Uso:**
```tsx
import { RainbowButton } from "@/components/ui/rainbow-button"

export function RainbowButtonDemo() {
  return <RainbowButton>Get Unlimited Access</RainbowButton>;
}
```
